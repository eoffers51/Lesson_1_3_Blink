# Project: Police Siren Lights

## Task

Write an ESP32 program that controls two LEDs (red and blue) and simulates police siren lights.

## Requirements

- Use two GPIO pins on the ESP32.
- Connect the red and blue LEDs through resistors.
- Implement a blinking sequence in which the red and blue LEDs blink alternately.
- The program must run in a continuous loop.

## Extras (optional)

- Make the blinking pattern more complex.
- Add a third LED.
- Vary the blinking speed.
- Reduce the number of pins used: make both LEDs blink alternately using only one GPIO pin.
